# 0002. 주석과 일회성 화면 답 받기

- 날짜: 2026-11-24
- 상태: 승인된 백로그 4·5의 구현 기록

## 결정
기존 interface·architecture 화면에는 카드별 주석, 명세에는 제목·문단·목록 항목별 주석을 붙인다. 복사와 보내기는 같은 글을 만든다. 선택하지 않은 카드의 주석도 포함한다.

Claude Code에서 `--wait`를 선택하면 Node 내장 HTTP로 loopback의 빈 포트에 한 번 쓰는 토큰 주소를 연다. 화면·Mermaid만 제공하고 토큰과 답을 확인한 첫 POST만 stdout에 전달한다. Host·Origin을 확인하고 요청 크기를 제한한다. 대기 중 중복 POST는 거절하며 성공 뒤 서버를 닫는다.

기본 540초 후에는 종료 코드 124로 끝낸다. 전송 실패 시 입력을 그대로 두고 복사 버튼으로 돌아간다. `--wait` 없이 실행하면 파일 생성과 복사 흐름을 유지한다.

## 이유
사용자가 기존 화면에 작은 주석 칸을 직접 두고 Claude Code만 먼저 지원하기로 결정했다. 540초는 Claude Code의 600초 실행 안에서 대기를 끝낸다. 서버를 분리해 기존 CLI 크기를 유지한다.

## 기각한 대안
- plannotator 연결: 사용자가 선택한 범위 밖이며 외부 도구가 필요하다.
- 새 웹 프레임워크: Node 내장 HTTP가 단일 화면과 한 번의 답 전달을 지원한다.
- 계속 켜 두는 서버·여러 답: 세션의 명령 한 번과 답 한 번이라는 범위보다 크다.

## 재검토
다른 호스트로 직접 전달하거나 여러 답을 받아야 할 때 다시 결정한다.
