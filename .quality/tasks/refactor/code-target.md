# "검사 대상 코드인가" 판정을 한 곳으로

## 의도
아키텍처 점검에서 고른 후보 2번. 같은 판정이 8곳에 따로 있어 어긋났다: "테스트 먼저 쓰기"·문서 영향 검사만 남의 코드(vendor·.min.)를 빼지 않아, 남의 코드만 고쳐도 테스트를 요구했다.
범위: 판정을 policy의 한 함수로 모으고 8곳이 그것을 쓴다. 각 검사의 추가 조건(테스트 파일·도구 파일·.sql 제외)은 그대로.

## 원하는 결과
모든 검사가 같은 기준으로 "우리 코드"를 고른다. 남의 코드만 바꾸면 테스트·문서를 요구하지 않는다. 비밀값 검사는 그대로 모든 파일을 본다.
