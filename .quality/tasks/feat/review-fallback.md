# Kiro 리뷰가 실패하면 새 Claude가 대신 리뷰 (H4)

## 의도
AI 리뷰는 되도록 코드를 쓴 AI와 다른 AI(Kiro)가 한다. Kiro 크레딧이 바닥나 리뷰가 막히는 일이 있다(2026-11 크레딧 100 미만). 사용자 결정 2026-11-27: Kiro 리뷰가 실패하면 코드를 쓴 대화와 떨어진 새 Claude(Sonnet)가 대신 리뷰하고, 완료 화면에 "같은 AI가 봄"과 바뀐 이유를 보인다.

정한 범위:
- 첫 리뷰 명령이 어떤 이유로든 실패하면(비정상 종료·시간 초과·결과 없음) 설정의 대신 돌릴 명령으로 한 번 더 돌린다.
- 대신 돌린 리뷰가 성공하면 완료로 저장하고, 완료 화면에 "같은 AI가 봄 — Kiro 리뷰가 실패해서 Claude가 대신 봄" 같은 한 줄과 첫 실패 이유를 보인다.
- 둘 다 실패하면 지금처럼 환경 오류로 멈춘다(두 실패 이유 모두 기록).
- 대신 돌릴 명령이 설정에 없으면 지금과 같다.
- 이 저장소 설정에 새 Claude(Sonnet) 리뷰 명령을 넣는다(사용자 허락 2026-11-27). 새 Claude는 이 대화의 훅을 돌리지 않는다.

## 원하는 결과
- 크레딧이 떨어져도 리뷰가 멈추지 않고, 누가 봤는지 완료 화면에서 안다.
