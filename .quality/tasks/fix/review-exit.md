# AI 리뷰가 중간에 죽으면 완료로 치지 않기 (C1)

## 의도
AI 리뷰 명령이 시간 초과나 비정상 종료로 끝나면, 결과 파일이 남아 있어도 "검토 완료"로 저장하지 않는다. 사용자 결정 2026-11-25: 실패로 본다.

## 원하는 결과
- 리뷰 명령이 0이 아닌 코드로 끝나거나 시간 초과면 리뷰 상태가 환경 오류가 되고 완료 화면이 만들어지지 않는다.
- 정상 종료 + 결과 파일이 있으면 지금처럼 완료.

## 성공 조건 → 검사
- 결과를 쓰고 exit 1로 끝난 리뷰 → 환경 오류 → test/qh.test.js
- 결과를 쓰고 시간 초과로 끝난 리뷰 → 환경 오류 → test/qh.test.js
- 기존 동작 유지 → npm test 전체
