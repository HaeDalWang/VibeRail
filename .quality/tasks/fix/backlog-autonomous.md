# 백로그 중 방향이 정해진 것 처리

## 의도
전면 리뷰 백로그 가운데 버그이거나 사용자가 방향을 이미 정한 항목만 고친다. 새 판단이 필요한 항목은 건드리지 않는다.

## 원하는 결과
- R1: 브랜치 없이 커밋만 꺼낸 상태(CI의 PR 검사)에서도 이번 작업의 카드를 찾아 열린 질문이 있으면 막는다.
- R2: 확인 질문·비밀값 면제는 긍정 답(예/네/돌려/진행)만 승인으로 친다.
- R3: 고른 안의 설계안을 읽지 못하면 조용히 넘어가지 않고 다시 묻는다.
- 그 밖에 리뷰 점검표·리뷰어 입력·결과지 숫자·규칙 우선순위·체험 마찰 일부·화면 문구·작은 것들.
