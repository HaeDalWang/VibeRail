# 사용자 화면의 qh를 VibeRail·품질 검사로

## 의도
비개발자가 보는 화면에 "qh"라는 뜻 없는 이름이 나온다(팀장 질문 1: 의미 있는 단어인가). 설치 이야기면 제품 이름 VibeRail, 하는 일 이야기면 "품질 검사"로 섞어 쓴다.

## 원하는 결과
질문 화면·결과지·설계안 화면에 "qh"가 보이지 않는다. AI가 읽는 표지("qh 답")와 명령 이름은 그대로 둔다.
